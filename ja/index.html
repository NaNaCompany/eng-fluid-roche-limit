流体衛星のロッシュ限界計算機

引張強度を持たない流体衛星が潮汐で分裂する古典的な距離を近似計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

中心から測った流体ロッシュ限界 d_R

—

値を入力し「計算する」を押してください。

公式

d_R = 2.44 R (ρ_M/ρ_m)^(1/3)

適用条件

すべての入力は正とします。球対称な主天体と、その円軌道を同期自転する軽い非圧縮性流体衛星を仮定し、係数を 2.44 に固定します。結果は高度ではなく中心間距離です。M=(4π/3)ρ_M R³ を求め、r_s(M)/R≤0.01 に制限します。剛体の強度、岩石の凝集力、非同期自転、楕円軌道、相対論は考慮しません。限界が主天体表面より内側なら、外部軌道に限界なしと表示します。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
